# 📊 DS-ML-Projects

A collection of **Data Science and Machine Learning projects** showcasing real-world problem solving using Python, data analysis, and predictive modeling.

---

## 🚀 About

This repository contains multiple projects focused on:

* 📈 Data Analysis
* 🤖 Machine Learning
* 🧠 Predictive Modeling
* 📊 Real-world problem solving

Each project is organized into separate folders with its own implementation and details.

## ▶️ How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/avcusnatsova/ds-ml-Projects.git
   ```

2. Navigate to the project folder:

   ```bash
   cd ds-ml-Projects
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the project:

   ```bash
   python filename.py
   ```
